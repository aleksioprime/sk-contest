# Типы мероприятий

Тип мероприятия — это шаблон: набор включённых модулей, анкета, этапы и лендинг по умолчанию.
Платформа строится вокруг механик, а не типов.

## Модули

| Модуль | Что даёт |
|---|---|
| Мероприятие | карточка, направления, этапы, даты, команда организаторов |
| Лендинг | сайт из блоков на поддомене или своём домене |
| Регистрация | анкета, приём заявок, модерация, кабинет участника |
| Этапы | движение по этапам, правила перехода, расписание |
| Оценивание | таблицы оценок, листы, судьи, анонимное голосование, рейтинг |
| Итоги | публикация результатов, дипломы, портфолио SkolStream |

## Типы

| Тип | Примеры | Регистрация | Оценка | Версия |
|---|---|---|---|---|
| Конкурс проектов и исследований | SkolStart, «Юный исследователь», защита ИП | команда и руководитель, файлы | жюри по критериям, анонимное голосование | MVP |
| Научно-практическая конференция | секции, доклады | докладчики с тезисами и слушатели | нет или «лучший доклад» | MVP |
| Творческий конкурс или фестиваль | рисунок, видео, музыка | индивидуально, медиа | жюри и зрители | MVP |
| Открытое событие | лекция, мастер-класс, день открытых дверей | слушатели, лимит мест, слоты | нет | MVP |
| Отбор | летняя школа, профильный класс, стипендия | анкета, письмо, документы | комиссия, затем собеседование | MVP |
| Хакатон, кейс-чемпионат | инженерные треки | индивидуально, команды на месте | чекпоинты и питч | v2 |
| Олимпиада | предметные олимпиады | индивидуально | баллы за задачи, шифрование, апелляции | v2 |
| Турнир | дебаты, ЧГК | команды | матчи, турнирная сетка | позже |

## Что нужно сверх MVP

- Конференция: программа по секциям, сборник тезисов, сертификаты слушателям.
- Творческий конкурс: галерея работ на лендинге, защита голосования от накруток.
- Открытое событие: QR-билет, отметка на входе, лист ожидания, отзыв после события.
- Отбор: запись на собеседование, решение «зачислен / резерв / отказ».
- Хакатон: подбор команд, треки, менторы.
- Олимпиада: шифрование работ, апелляции, протоколы.
