# План работ

Оценки даны для одного разработчика. Старт 19.10.2026. Около 16 рабочих недель, MVP в середине января.
При втором разработчике этап 6 можно вести параллельно с этапами 4–5.

| Этап | Срок | Веха |
|---|---|---|
| 0. Подготовка | 1 нед | приложение разворачивается в UAT |
| 1. Ядро: люди, вход, права | 2 нед | вход через SkolStream и по email |
| 2. Мероприятия | 1,5 нед | организатор настраивает мероприятие |
| 3. Регистрация и заявки | 2,5 нед | **~04.12** можно открыть приём заявок |
| 4. Оценивание | 2,5 нед | полный цикл оценки этапа |
| 5. Этапы и итоги | 1,5 нед | **~15.01 MVP**: мероприятие от заявки до диплома |
| 6. Конструктор лендингов и домены | снято | заявки из внешних сервисов через вебхук |
| 7. Интеграции, перенос истории, пилот | 1,5 нед | **~17.02** запуск, отключение старой системы |

Новогодние каникулы 28.12–10.01 учтены.
